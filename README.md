# Сервис для автоматизации заказа справок в бухгалтерии. Сотрудники создают заявки, бухгалтеры обрабатывают их в единой очереди.

# Функциональность

# ✅ Создание заявок на справки (2-НДФЛ, о стаже, о среднем заработке, произвольная)

# ✅ Просмотр своих заявок для сотрудника

# ✅ Очередь заявок для бухгалтера

# ✅ Изменение статусов заявок (в работу, завершено, отклонено)

# ✅ Защита от повторных отправок (идемпотентность)

# ✅ Валидация входных данных

# ✅ FIFO очередь для бухгалтера

# ✅ Обязательная причина отказа при отклонении

# 

# Сервис использует идемпотентность на основе SHA256 хеша параметров запроса:

# При первом запросе создаётся заявка и сохраняется хеш

# Ключи автоматически очищаются через 24 часа

# 

# Для валидации изменения статуса справок используется машина состояний 

# 

# Откройте https://localhost:\[номер хоста] /swagger

# Создайте заявку через POST /api/employee/requests

# Скопируйте полученный requestId

# Посмотрите очередь через GET /api/accountant/requests

# Измените статус через PATCH /api/accountant/requests/{id}/status
